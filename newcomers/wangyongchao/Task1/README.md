## 一、 开发工具链与环境搭建

### 1. 现代 AI IDE 配置 (Trae)
受限于年龄（未成年）无法实名注册外部大模型 API（如 SiliconFlow、DeepSeek）。因此我选择了**字节跳动推出的 Trae CN**作为主力开发环境，它开箱即用，内置大模型服务，完美解决了 API 获取困难的问题。

- **核心插件配置**：安装了 `Python`、`Prettier`，并根据 IDE 推荐安装了 `BasedPyright`（类型检查）和 `GitLens`（版本控制）。

### 2. 终端协同工具实战
由于无法获取 OpenCode/DSH 等 CLI 工具所需的 API Key，我采用 **Trae AI 助手 + 本地 PowerShell 终端** 的替代方案，完成了终端级的交互式代码审查与调试。

**实战案例：编写并调试 `primes.py`（打印 1-100 的质数）**
1. 让 Trae 生成初始脚本。
2. 在终端运行中故意制造错误，通过复制终端报错信息交给 Trae 进行纠错。
3. 最终在 PowerShell 终端成功运行，输出 25 个质数。
